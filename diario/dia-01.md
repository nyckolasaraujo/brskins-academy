*/ Qual a diferença entre git commit e git push? O que acontece se você fizer commit e fechar o computador sem push? /
A diferença é que o git commit serve como uma foto que fica salvo no propio sistema, já o git push ele manda os arquivos para a  nuvens no caso o github.
*/O que o painel Source Control do VS Code está fazendo por baixo dos panos quando você clica no "+" e depois em "Commit"?/
Ele adicionando no chance todas as alteraçoes feita e depois clicando em commit ele esta salvando no propio sistema.
